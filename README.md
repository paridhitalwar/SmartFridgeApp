# Smart Fridge Tracker

A unified mobile and web application to track food inventory, plan meals, and get AI recipe suggestions.

## Project Structure
* `/CS633-Team-2`: React Native / Expo Frontend Application.
* `/backend-src`: Node.js / Express Backend API.

## Local Development
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the backend:
   ```bash
   npm start
   ```
3. Run the Expo app:
   ```bash
   cd CS633-Team-2
   npx expo start
   ```
